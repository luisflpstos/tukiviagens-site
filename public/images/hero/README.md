# Hero da home

Coloque aqui a foto principal do hero.

**Arquivo esperado:** `capa.jpg` ou `capa.webp` (referência em `src/lib/image-paths.ts` → `IMAGE_PATHS.hero`)

## Recomendações

| | Valor |
|---|---|
| Proporção | Paisagem — **16:9** ou **3:2** |
| Dimensões | **2400×1350** (16:9) ou **2000×1333** (3:2); mínimo **2000px** de largura |
| Formato | `.webp` (preferível) ou `.jpg` (qualidade 80–85%) |
| Peso | 200–400 KB (WebP) / até ~500 KB (JPG otimizado) |
| Assunto | Resort/família no Brasil — foto real da operação ou parceiro |

Desktop e mobile usam o **mesmo arquivo**. O CSS aplica `object-cover`, overlay roxo (~55%) e animação Ken Burns — mantenha o assunto centralizado e evite detalhes importantes nas bordas.
